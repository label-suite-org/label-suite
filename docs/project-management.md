# Project management

The public source candidate is `label-suite-org/label-suite` on GitHub.
The existing private repository retains its backlog and historical evidence.
See [publication status](../PUBLIC_SOURCE.md) and [agent instructions](../AGENTS.md).
Do not copy private issues, research, or logs into public pull requests.

Use a named branch, focused verification, and a reviewed GitHub pull request for
public changes. Distinguish implemented, tested, merged, deployed, and accepted.
Forgejo references in older specifications are historical, not current authority.
